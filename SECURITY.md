# Security policy

## Supported versions

Design Harness is in alpha. Security fixes are applied to the latest commit on `main`. There is no supported stable release yet.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's **Report a vulnerability** action in the Security tab of the Design Harness repository.

Include the affected commit or version, the impact, reproduction steps, and any suggested mitigation. Do not include real credentials, provider transcripts, or private project files.

If private vulnerability reporting is not available, contact the repository owner through the public profile and ask for a private reporting channel. Do not send sensitive details until a private channel is confirmed.

## Scope

High-priority areas include provider command execution, filesystem access, Git restore operations, desktop protocol handling, update packages, authentication data, and exposure of local services.
